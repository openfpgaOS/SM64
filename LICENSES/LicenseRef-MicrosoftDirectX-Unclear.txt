LicenseRef-MicrosoftDirectX-Unclear
===================================

THIS IS NOT A LICENSE. It is a statement of what could and could not be
verified about the Microsoft-authored Direct3D 12 headers vendored under
src/sm64/sm64/src/pc/gfx/dxsdk/.

What this identifier marks
--------------------------

  * src/pc/gfx/dxsdk/d3d12.h
  * src/pc/gfx/dxsdk/d3d12sdklayers.h
  * src/pc/gfx/dxsdk/d3dcommon.h

These are MIDL-compiler-generated Direct3D 12 interface headers from the
Windows SDK. They are used only by the upstream port's Windows Direct3D 12
backend (src/pc/gfx/gfx_direct3d12.cpp), which this project does not build.

Evidence of provenance (verified in-tree, not assumed)
------------------------------------------------------

  d3d12.h:3            " * Copyright (c) Microsoft Corporation"
  d3d12sdklayers.h:3   " * Copyright (c) Microsoft Corporation"
  d3dcommon.h          MIDL-generated; carries no copyright line at all.

All three carry the MIDL banner "File created by MIDL compiler version
8.01.0622" and "this ALWAYS GENERATED file contains the definitions for the
interfaces".
